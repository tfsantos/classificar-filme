# Classificação de filmes - Exercício 5 de Lógica de Programação

Repositório utilizado para a entrega da tarefa da aula extra de Lógica de Programação da Mentoria 2.0 - Turma 5

Enunciado

Exercício 5: Criar um projeto node no vsCode, seguindo a estrutura já compartilhada na aula 4, contendo o código de aplicação/fonte e arquivos de teste. Deve conter ao menos 3 casos de teste em cada um dos exercícios. Entrega por meio de um repositório do github atualizado. Você tem um vetor com notas de diferentes usuários para os respectivos filmes: 

Entrada: [ 
  {nome: "Minha mãe é uma peça", avaliações: [5,4,4,4,5]}, 
  {nome: "Saneamento Básico", avaliações: [3,4,2,3,4]}, 
  {nome: "Se eu fosse você", avaliações: [1,2,3]} 
]

Saída: 
  Quantas pessoas votaram no filme? 
  Qual é a média das notas? 
  
Deve retornar a avaliação: 
  Media >=4 "Filme recomendado" 
  Media entre 3 e 4 "Filme razoável" 
  Média <3 "Filme ruim""
